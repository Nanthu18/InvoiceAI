---
description: How to run the InvoiceAI application
---

1. Ensure you have your Gemini API key ready from [Google AI Studio](https://aistudio.google.com/).
2. Open the `.env` file and replace `your_key_here` with your actual API key.
// turbo
3. Run the application:
   ```bash
   python app.py
   ```
4. Open your browser and navigate to `http://localhost:8000`.
5. Upload a PDF invoice and see the magic!
